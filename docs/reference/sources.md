## 文丘里量级参考

[Netafim Venturi Injectors 官方数据表](https://www.netafim.com/contentassets/f7aa9082789344829a612608f3b52d06/jul2021_kc_venturi-injection-product-page-2021-final.pdf?v=4a585c)同时列出入口压力、出口压力、驱动流量和吸液量，并明确订货需要提供最小/最大流量、允许压损、入口压力和目标吸液量。

本仓库引用其中 3/4 英寸型号的一个工况（约 14 m 入口水头、3 m 出口水头、522 L/h 驱动流量）作为数量级警示，不构成品牌或型号推荐，也不能外推到其他“4 分”产品。

## 每个采购型号必须归档的数据

| 设备 | 必需数据 |
| --- | --- |
| 双路控制器 | A/B 独立计划数、最小流量、压力范围、反压、离线计划、断电状态 |
| 文丘里 | 全部有效 P1/P2/驱动流量/吸液量曲线、安装方向、最大压力、材料 |
| MV-END | 三位三通结构、中位全关、两个工况的通径/压损、锁定位、最大压力、材料和无内部串通 |
| MV-SOURCE | 三位三通结构、中位全关、真空密封、低死体积、材料兼容、可清洗性和无内部串通 |
| 后续电动三通执行器 | 电压、最低流量/压差、Kv、失电安全位置、切换过程和阀位反馈；仅在手动水力验收后选型 |
| 滴灌/喷灌调压阀 | 设定范围、最小流量、最小入口压差、低流量稳定性 |
| 公共/喷灌过滤器 | 实际过滤精度、额定流量、洁净/堵塞压损、最大压力 |
| 止回阀 | 工程塑料材质、开启压力、低流量压损、最大反压、安装方向、密封和介质兼容；不默认采用黄铜 |
| 滴头 | 标称流量、起调压力、工作压力范围、过滤要求、制造偏差 |
| 上空喷头 | 流量—压力曲线、覆盖范围、过滤要求、材料、安装间距 |
| 滴灌/喷灌管 | 实际内径、壁厚、额定压力、材料、温度和抗紫外能力 |

将取得的数据表保存在受控资料位置，并在计算页记录型号、版本和核对日期。商品标题、客服聊天截图和接口照片只能作为辅助证据。

## 图像资源与制作工具

- `fertigation-system-topology-v4.svg`：从 v4 接口规格事实 JSON 与布局配置生成的确定性工程拓扑图。
- `fertigation-system-topology-v4.png`：由同一 SVG 自动渲染的 2400 px 高清版本。
- `fertigation-installation-reference-v1.png`：上一版单桶滴灌安装参考，保留用于版本追溯。
- `fertigation-installation-reference-v2.png`：上一版四只支路阀空间参考，保留用于追溯。
- `fertigation-installation-reference-v3.png`：在 v2 基础上纠正为两只三通选择阀、单端喷灌进水和无回环的当前空间参考；它不作为端口数量或流向的事实源。

v3 实景图约束包括：单一水源、B 路完整穿过共用文丘里、CV-F/CV-P 后由 MV-SOURCE 三通阀选择母液、A/B 合流后由 MV-END 三通阀选择末端、滴灌独立减压、喷灌独立过滤/调压、喷灌横管单端进水且无回环、四盆上方喷头、无品牌和无文字。旋钮控制盒与电线不属于当前手动版本。

- **必需图片插件：无。** 工程拓扑图使用 SVG 确定性绘制，高清 PNG 由 SVG 渲染。
- **可选插件：Figma。** 仅在需要可拖拽源文件或多人继续排版时安装；MkDocs、SVG 和 PNG 交付不依赖它。

## 数据与工作簿

- `system-interfaces.xlsx` 是设备端口、牙型、管径、测点和过滤参数的人工维护入口。
- `current-design-calculation.xlsx` 是独立工程计算与现场记录入口。
- `system-interfaces.data.json` 和 `current-design-case.data.json` 是同步生成的事实清单，不手工编辑。
- Excel、网页计算器、工程图和文档表格使用相同字段与固定单位；缺少厂家资料时统一显示“待确认”。
