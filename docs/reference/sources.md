## 文丘里量级参考

[Netafim Venturi Injectors 官方数据表](https://www.netafim.com/contentassets/f7aa9082789344829a612608f3b52d06/jul2021_kc_venturi-injection-product-page-2021-final.pdf?v=4a585c)同时列出入口压力、出口压力、驱动流量和吸液量，并明确订货需要提供最小/最大流量、允许压损、入口压力和目标吸液量。

本仓库引用其中 3/4 英寸型号的一个工况（约 14 m 入口水头、3 m 出口水头、522 L/h 驱动流量）作为数量级警示，不构成品牌或型号推荐，也不能外推到其他“4 分”产品。

## 每个采购型号必须归档的数据

| 设备 | 必需数据 |
| --- | --- |
| 双路控制器 | A/B 独立计划数、最小流量、压力范围、反压、离线计划、断电状态 |
| 文丘里 | 全部有效 P1/P2/驱动流量/吸液量曲线、安装方向、最大压力、材料 |
| 减压阀 | 设定范围、最小流量、最小入口压差、低流量稳定性 |
| 过滤器 | 实际过滤精度、额定流量、洁净/堵塞压损、最大压力 |
| 止回阀 | 开启压力、低流量压损、最大反压、安装方向、材料 |
| 滴头 | 标称流量、起调压力、工作压力范围、过滤要求、制造偏差 |
| PE/毛管 | 实际内径、壁厚、额定压力、温度和抗紫外能力 |

将取得的数据表保存在受控资料位置，并在计算页记录型号、版本和核对日期。商品标题、客服聊天截图和接口照片只能作为辅助证据。

## 图像资源与制作工具

- `fertigation-system-topology-v3.svg`：从接口规格事实 JSON 与布局配置生成的确定性工程拓扑图。
- `fertigation-system-topology-v3.png`：由同一 SVG 自动渲染的 2400 px 高清版本，便于分享和打印。
- `fertigation-installation-reference-v1.png`：使用内置图像生成功能生成的无品牌安装参考；它不作为阀门方向或接口数量的事实来源。

生成实景图的最终提示约束包括：单一水源路径、B 路完整穿过文丘里、A/B 在减压阀前合流、肥桶只接侧吸口、三只止回阀、无品牌和无文字。

- **必需图片插件：无。** 工程拓扑图使用 SVG 确定性绘制，高清 PNG 由 SVG 渲染。
- **可选插件：Figma。** 仅在需要可拖拽源文件或多人继续排版时安装；MkDocs、SVG 和 PNG 交付不依赖它。

## 数据与工作簿

- `system-interfaces.xlsx` 是设备端口、牙型、管径、测点和过滤参数的人工维护入口。
- `current-design-calculation.xlsx` 是独立工程计算与现场记录入口。
- `system-interfaces.data.json` 和 `current-design-case.data.json` 是同步生成的事实清单，不手工编辑。
- Excel、网页计算器、工程图和文档表格使用相同字段与固定单位；缺少厂家资料时统一显示“待确认”。
