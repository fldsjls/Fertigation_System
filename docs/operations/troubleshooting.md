# 故障诊断

> 文档类型：V4 现场诊断表
> 最后核对日期：2026-07-24

先记录当前手动模式、手机 A/B 状态、MV-END/MV-SOURCE 位置、P0～P5、末端总流量和两桶液位，再拆卸部件。禁止用错误液源/末端配对或增加农药剂量试错。

| 现象 | 优先检查 | 处置 |
|---|---|---|
| 停止模式仍出水 | A/B 阀芯、MV-END 是否真正位于中位全关 | 关闭水源，修复前停用 |
| 双末端同时出水 | MV-END 是否选错型号、阀芯是否内部串通 | 停用并更换为中位全关的单选三通阀 |
| 两桶同时被吸 | MV-SOURCE 是否内部串通、CV-F/CV-P 是否失效 | 立即停机，隔离并清洗污染支路 |
| 农药进入滴灌 | 是否误设 MV-SOURCE=农药、MV-END=滴灌 | 停止、隔离、按标签和现场要求处理，不继续灌溉 |
| 肥料进入喷灌 | 是否误设 MV-SOURCE=肥料、MV-END=喷灌 | 停止并清水置换，完善人工复核 |
| A 路运行时桶液位上升 | CV-B、CV-F、CV-P 方向与开启压力 | 检修止回阀和反压，不仅检查控制器 |
| 三通阀换位困难或渗漏 | 通径、密封、材料兼容、锁定位与清洗 | 更换合适三通阀；电控升级前先解决水路问题 |
| 滴灌 P4 低 | 公共过滤器、MV-END 滴灌位、滴灌减压、水源动态压力 | 分段测压，按当前流量压损核对 |
| 喷灌 P5 低 | 喷灌管径、MV-END 喷灌位、喷灌过滤/调压、喷头总流量 | 用网页/工作簿重算；不可直接套用 9/12 管 |
| 近端喷头强、远端弱 | 管径、长度、高差、喷头孔径差异 | 记录各喷头压力/流量，优化管径或分区 |
| 滴灌能吸肥、喷药不吸 | 喷药工况 P1/P2、驱动流量、喷灌背压、厂家曲线 | 两工况分别判定，不能沿用滴灌结论 |
| 喷药能吸、滴灌不吸 | 8 L/h 低流量、文丘里最小驱动流量 | 更换适用型号或改变滴灌工况 |
| 吸液管出现气泡 | 过滤头液位、接头密封、软管裂纹、调节阀 | 先以清水排气和查漏 |
| 喷药后置换不足 | 共用段/喷灌管内容积、实测清水流量、标签载水量 | 延长至规定置换量，记录实际终点 |

## 诊断顺序

1. 确认模式组合合法；
2. 确认当前只启用一个末端和最多一个液源；
3. 记录 P0、P3 以及 P4 或 P5；
4. B 路问题再记录当前工况的 P1/P2、驱动流量和吸液量；
5. 对照拟购型号曲线、当前流量压损和管径计算；
6. 修复后重新完成对应清水调试矩阵。
