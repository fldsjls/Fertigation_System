# 故障诊断

> 文档类型：现场故障排查  
> 最后核对日期：2026-07-23  
> 事实来源：系统测压点、流向契约和厂家数据表

先记录当前是 A 还是 B、P0～P3、滴头总流量、桶液位和阀门状态，再拆卸部件。不要通过同时打开 A/B 或提高肥液浓度试错。

| 症状 | 优先检查 | 判定与处理 |
| --- | --- | --- |
| B 开启但完全不吸液 | P1/P2、驱动流量、文丘里方向、吸管漏气、调节阀 | 若工作点不在厂家曲线内，文丘里不适用；不要按接口尺寸强行使用 |
| 吸液量很小或波动 | 桶液位高度、过滤头堵塞、软管折弯、P0 波动 | 清洁过滤头并排气；在稳定工况重新测 `q吸` |
| A 运行时桶液位上升 | B 路止回阀、吸肥止回阀 | 立即停机；修复前禁止施肥 |
| B 运行时 A 口反压 | A 路止回阀 | 检查方向、阀芯杂物和开启/关闭压力 |
| A 正常、B 滴头压力低 | 文丘里压损、B 止回阀、控制器 B 口 | 对照 P0/P1/P2/P3；必要时改用计量泵 |
| A、B 均压力低 | 水源动态压力、过滤器堵塞、倒流防止器压损、减压阀 | 清洁过滤器；不要用静态压力代替动态压力 |
| 近端正常、远端流量低 | 管径、管长、高差、末端堵塞 | 按 Darcy–Weisbach 重算，冲洗末端并测各点压力 |
| 施肥后仍有高电导率 | 冲洗体积不足、死角、末端未打开 | 延长 A 冲洗并以末端水质恢复为终点 |
| 控制器显示执行但无水 | 阀门最低压力/流量、电量、入口方向 | 手动单路测试并核对产品下限 |
| 两路同时有水 | 计划重叠、阀芯故障或接线/固件问题 | 立即关闭水源；恢复互斥前停止自动运行 |

## 文丘里与计量泵的分界

出现以下任一情况，停止继续优化当前文丘里：

- 厂家最小驱动流量高于 `Q设计`；
- 达到吸液压差后 P3 已低于滴头最低压力；
- 吸液量无法在目标范围稳定调节；
- 为启动文丘里必须让 A、B 同时打开；
- 厂家不能提供当前入口/出口压力下的性能曲线。

替代的小型计量泵应按目标吸液量、注入点压力、材料兼容性和防虹吸/止回能力选型。计量泵并不取消水源倒流防护、支路止回和清水冲洗要求。

## 过滤与析出

若肥液含有沉淀、结晶或混配不相容：

1. 停止吸肥，切换 A 路清水冲洗。
2. 清洁桶内过滤头、调节阀、文丘里侧吸口和滴头。
3. 核对肥料溶解度、母液配制顺序和水质。
4. 重新清水测试，不在堵塞状态下提高入口压力。
