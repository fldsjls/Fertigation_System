# A → B → A 控制程序

> 文档类型：运行控制契约  
> 最后核对日期：2026-07-23  
> 事实来源：系统设计、控制器厂家功能和现场调试结果

## 状态机

```text
待机
  ↓
A 预灌
  ↓ A关闭并确认
切换间隔
  ↓
B 施肥
  ↓ B关闭并确认
切换间隔
  ↓
A 冲洗
  ↓
待机
```

任何时刻最多打开一路。切换间隔应覆盖控制器阀门实际关闭时间和压力稳定时间；在没有厂家数据前，通过清水调试确定，不统一写死为某个秒数。

## 参数

| 参数 | 含义 | 确定方法 |
| --- | --- | --- |
| `t预灌` | A 路预湿时间 | 植物需水、土壤/基质和目标湿润深度 |
| `t间隔` | A/B 切换间隔 | 阀门关闭确认和压力稳定测试 |
| `t施肥` | B 路运行时间 | 所需灌溉体积、目标浓度和实测 `q吸` |
| `t冲洗` | A 路末端冲洗时间 | 管内容积与末端电导率恢复测试 |

## 示例计划

以下只演示同日 `A → B → A` 排列，不是最终肥量或冲洗时长：

```text
06:00:00  A 打开
06:05:00  A 关闭
           等待 t间隔
06:05:00+t间隔  B 打开
06:15:00+t间隔  B 关闭
                 等待 t间隔
06:15:00+2×t间隔 A 打开
06:20:00+2×t间隔 A 关闭
```

如果控制器只能按分钟设置，不能表达秒级间隔，应通过不重叠的整分钟计划留出安全窗口，不要让 A、B 时间边界相同。

## 购买前功能门槛

- A、B 每天可分别设置多个计划。
- 同一天允许 A 再次启动，即能表达 A→B→A。
- 系统能够阻止计划重叠，或用户可以设置可靠的不重叠窗口。
- 断网、手机离线时，控制器仍按本地时钟执行。
- 断电/低电量行为明确，默认状态为两路关闭。
- 关闭状态可承受合流点和主管侧反压。
- 最低启动水压、最低可控流量和最大工作压力覆盖现场条件。
- 支持手动开关单一路，便于清水调试。

任一核心门槛不满足时，不通过“增加第三个肥液电磁阀”掩盖控制器能力不足；应更换控制器或改变控制架构。

## 异常处理

| 异常 | 自动动作 | 人工处理 |
| --- | --- | --- |
| A/B 计划重叠 | 两路关闭或只保留明确优先级的一路 | 修正计划，重新做互斥测试 |
| B 路无吸液 | 停止施肥并转清水冲洗 | 检查曲线、P1/P2、方向和吸气 |
| P3 低于滴头范围 | 关闭当前路径 | 检查过滤器、阀门压损和水源动态压力 |
| 桶液位异常上升 | 立即关闭 A/B | 检查 B 止回阀和吸肥止回阀 |
| 控制器低电量/离线 | 禁止开始新的施肥周期 | 更换电池，验证本地时钟和计划 |

## 计划变更记录

每次改变滴头数量、母液浓度、肥料种类、文丘里调节阀位置、管路长度或水源压力后，都应重新核对 `t施肥`、`t冲洗` 和 B 路压力数据。手机页面显示“计划已保存”不等于现场水力验收通过。
