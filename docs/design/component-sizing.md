# 部件选型与数量计算

> 文档类型：设计与采购核对  
> 最后核对日期：2026-07-23  
> 事实来源：系统原理、所购设备数据表、现场尺寸与水质

## 设计输入

以未来同一时刻实际工作的滴头数量作为 `N`，不要使用已购买但不会同时开启的总数量。

```text
Q设计 = N × q滴头
```

若一个滴头标称 `2 L/h`：

| N | Q设计 |
| ---: | ---: |
| 4 | 8 L/h |
| 20 | 40 L/h |
| 50 | 100 L/h |

流量只是第一道门槛。过滤器、控制器、止回阀、文丘里和减压阀还必须在该流量下正常工作；“接口都是 4 分”不代表性能匹配。

## 接口表达规则

- 主水路当前采用 `G1/2（俗称4分）` 作为候选框架；它不表示具体设备已经确认，也不包含内牙/外牙信息。
- P0～P3 测压三通采用 `G1/4（俗称2分）` 作为候选框架，端口形式和端面密封仍待厂家确认。
- `9/12` 与 `3/5` 表示管材的**内径/外径毫米值**，不是“9分管”或“3分牙”。
- G、R、Rp、Rc 和 NPT 必须逐端口记录；只写“4分”不足以采购转接件。

当前逐端口数据、止回阀尺寸和自动转接建议见[接口、牙型与管径清单](../reference/interface-schedule.md)。人工维护入口为可下载的 `system-interfaces.xlsx`，修改后通过数据同步命令统一更新图纸和本文档。

## 文丘里硬性选型门槛

只有以下四项同时满足才能采购：

1. `Q驱动 = Q设计 - q吸` 位于厂家给出的驱动流量范围内。
2. 现场 P1 动态压力能够达到曲线所需入口压力。
3. P1 与 P2 的差值不会使下游 P3 低于滴头所需压力。
4. 对应工况的吸液量覆盖目标 `q吸`，且调节范围可控。

任一数据缺失，结论为“待确认”；厂家曲线明确不覆盖时，结论为“不适用”。不得用“4 分文丘里”或“最大吸肥量”替代工况曲线。

### 低流量量级警示

Netafim 3/4 英寸产品曲线的一个低端工况为入口水头约 14 m、出口水头约 3 m、驱动流量约 522 L/h。它不是本项目的购买推荐，只用于说明接口尺寸不能代表微流量能力。

文丘里入口的驱动水和侧吸液在出口合并：

```text
Q设计 = Q驱动 + q吸
N最低 = 向上取整[(Q驱动 + q吸) ÷ q滴头]
```

Netafim 上述工况同时列出约 `522 L/h` 驱动流量和 `215 L/h` 吸液量，下游合计约 `737 L/h`。若完全照用该工况和 `2 L/h` 滴头，约需 `737 ÷ 2` 向上取整，即 369 个同时工作滴头。这个换算仍只是量级示例；实际 `N最低` 必须使用拟购型号、目标吸液量和同一个曲线工况。

## 管径和过滤精度

- `9/12` 与 `3/5` 只是候选规格，计算必须使用厂家标注或实测**内径**。
- 过滤精度由滴头最小流道和厂家要求决定；“120目”需核对滤网标准和实际微米值。
- 过滤器应位于文丘里上游以保护其喷嘴。肥料必须充分溶解，吸肥端使用桶内过滤头；是否增加下游二次过滤器要结合肥料析出风险和新增压损单独设计。
- 止回阀开启压力在小流量系统中可能比管道沿程损失更重要，应取得低流量压损数据。

## 材料兼容

肥液接触件至少包括桶内过滤头、软管、调节阀、吸肥止回阀、文丘里侧吸部件和密封。采购前按具体肥料名称、浓度、温度核对 PP、PVC、EPDM、FKM/Viton、不锈钢弹簧等材料，不根据“耐酸碱”宣传语直接推断。
