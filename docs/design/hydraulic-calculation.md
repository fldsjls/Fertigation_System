# 滴灌、喷淋与文丘里计算方法

> 文档类型：V5 计算方法与验收边界
> 最后核对日期：2026-07-25

## 流量模型

```text
Q滴灌 = N滴头 × q滴头
Q喷淋 = N喷头 × q喷头
Q节点支管 = 2 × q滴头
Q毛管 = q滴头
```

正式默认值为 `N滴头=10`、`N喷头=5`、每节点 2 只滴头。主管按滴灌总流量计算，OD12 节点支管按 2 只滴头流量计算，3/5 毛管按单只滴头流量计算。

## 三类滴灌管段

| 管段 | 已知参数 | 仍需确认 |
| --- | --- | --- |
| 9/12 主管 | ID9/OD12、10 只滴头总流量 | 总长度、局部阻力 |
| OD12 节点支管 | OD12、每段服务 2 只滴头、共 5 段 | 实际内径、每段长度、粗糙度、局部阻力 |
| 3/5 滴箭毛管 | ID3/OD5、单只滴头流量、共 10 条 | 每条长度和实际材料 |

总管内容积为：

```text
V总 = V主管 + 5 × V节点支管 + 10 × V毛管
```

OD12 节点支管参数缺失时，总内容积和相关末端压力保持“待确认”，不会用外径 12 mm 代替内径。

## 管路压损

对每段管使用 Darcy–Weisbach：

```text
A = πD²/4
v = Q/A
Re = vD/ν
ΔP = [f(L/D) + ΣK]ρv²/2
```

- `Re < 2300` 时采用 `f=64/Re`；
- `2300≤Re≤4000` 保持“待确认”；
- 湍流采用显式摩阻近似，但必须提供材料粗糙度；
- 单位统一后输出 MPa。

公式结果是计算值，不代替管材厂家额定压力、现场流量或验收。

## 滴头与喷头压力

滴头可用压力：

```text
P滴头 = P4 - ΔP主管 - ΔP节点支管 - ΔP毛管 - ΔP其他 - ρgΔz
```

喷头可用压力：

```text
P5 = P3 - ΔP喷淋管 - ΔP喷淋过滤/调压/管件 - ρgΔz
```

下游滴灌调压器和喷淋调压器只有在 P4/P5 实测、末端厂家工作范围及最低流量确认后才能选型。

## B 路压力预算

B 路在 T1/T2 之间为并联，不是串联：

```text
T1 ┬→ 减压阀主路 ─┬→ T2
   └→ 文丘里旁路 ─┘
```

同一工况下：

```text
ΔP旁路 = P1 - P2
```

压力预算对该压差只计算一次：

```text
P源,需 =
  P末端调压设定
  + ΔP末端调压最小工作压差
  + ΔP倒流防护
  + ΔP过滤器
  + ΔP控制器B
  + (P1-P2)
  + ΔP止回及其他管件
```

不得使用“减压阀损失＋文丘里损失”再叠加 `P1-P2`。优先使用同一运行工况的实测 P1/P2；没有实测时，只能使用已确认厂家曲线工况或明确标记的候选压差。

## 文丘里驱动流量

B 路末端流量满足：

```text
Q末端 = Q减压主路 + Q文丘里驱动 + q吸
```

因此：

- `Q末端-q吸` 是并联两条水路的清水总量；
- 它不是 `Q文丘里驱动`；
- 滴灌施肥和上空喷药必须分别实测文丘里旁路驱动流量。

文丘里判定同时需要实际 P1/P2、实际驱动流量、厂家允许驱动流量范围、同工况曲线点和目标吸液量。状态规则：

| 条件 | 状态 |
| --- | --- |
| `P1≤P2`、实际驱动流量超范围、曲线吸液量不足 | 不适用 |
| 缺实际驱动流量、缺 P1/P2、缺同工况厂家曲线 | 待确认 |
| 数据齐全且公式校核通过 | 已计算；仍需现场清水验证 |

## 吸液质量平衡

目标吸液量由末端总流量和浓度质量平衡计算：

```text
q吸 = Q末端 × (C目标-C水) / (C母液-C水)
V母液 = q吸 × t
V桶,最低 = V母液 + 不可吸残余量
```

这只给出目标吸液量，不会反推出文丘里驱动流量。农药浓度、施用方法和载水量必须来自登记标签。

## 冲洗和均匀性

冲洗时间的理论起点：

```text
t冲洗 = 60 × V管内 / Q冲洗,实测
```

滴灌最终以末端水质恢复和逐节点冲洗为准。喷药后按喷淋管内容积和实测清水置换流量计算，并服从标签允许的总载水量。

滴头均匀性使用统一时间采样和低四分位分布均匀度：

```text
DUlq = q低四分位平均 / q总体平均 × 100%
```
