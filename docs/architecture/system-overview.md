# 系统原理

> 文档类型：当前设计事实  
> 最后核对日期：2026-07-24  
> 事实来源：ADR 0001、系统工程拓扑图和设备待确认参数

## 设计基准接法

```text
水源
  │
合规倒流防止器
  │
120目过滤器
  │
双路控制器
  ├── A路 ── 低开启压力止回阀 ─────────┐
  │                                    ├─ 合流三通 ─ 减压阀 ─ 9/12主管 ─ N个支路
  └── B路 ── 文丘里 ── 低开启压力止回阀 ┘
                 │
              侧吸口
                 │
           耐肥液止回阀
                 │
               调节阀
                 │
             桶内过滤头
                 │
               肥液桶
```

水源只能进入倒流防止器和过滤器，不允许另有任何管线直通主管。B 路的两个大口分别是水入口和水出口；B 路全部水流必须从大入口进入、穿过文丘里、从大出口离开。肥液桶只连接文丘里的小型侧吸口。

## 两种运行状态

| 状态 | A 路 | B 路 | 肥液桶 | 结果 |
| --- | --- | --- | --- | --- |
| 清水预灌/冲洗 | 开 | 关 | 与主管隔离 | 清水经 A 路进入主管 |
| 施肥 | 关 | 开 | 经侧吸口被吸入 | 全部驱动水先穿过文丘里，再进入主管 |
| 停机 | 关 | 关 | 止回阀阻止倒灌 | 系统保持关闭 |

A、B 不需要同时打开。第三只肥液电磁阀不是本设计的必要条件；B 路关闭后文丘里失去驱动水流，吸肥停止。但吸肥软管仍必须安装耐肥液止回阀，防止主管压力把水压回肥液桶。

## 三层防倒流不能互相替代

1. **水源倒流防止器**：保护生活饮用水或上游供水系统，按当地污染风险等级和规范选型。
2. **A/B 支路止回阀**：阻止合流点压力反向进入未工作的控制器出口。
3. **吸肥止回阀**：阻止水从文丘里侧吸口倒灌至肥液桶。

双路控制器的关闭阀芯不是专用倒流防止装置。即使厂家宣称阀门“关闭不漏”，也不能删除上述止回保护。

## 减压阀为什么位于合流后

合流后减压可让 A、B 共用同一个滴灌工作压力，并让 B 路入口尽量保留水源压力。但减压阀位于文丘里下游，并不等于文丘里一定获得足够压差：文丘里的工作点仍由入口压力、出口背压、驱动流量和内部几何共同决定。

## 按工程图分段分析

| 图中区段 | 当前设计事实 | 验证手段 |
| --- | --- | --- |
| 共用上游 | 水源只有一条路径，依次经过倒流防止器、过滤器和控制器 | 核查连接顺序，记录 P0 动态压力 |
| A 路 | 清水经 A 止回阀进入合流点 | A 运行时确认 B 路和肥液桶无反向窜流 |
| B 路 | 全部驱动水完整穿过文丘里，再经过 B 止回阀 | 记录 P1、P2、`Q驱动` 和 `q吸`，对照厂家曲线 |
| 共用下游 | A/B 在止回后合流，再经减压阀进入主管 | 记录 P3 和 `Q设计`，验证滴头压力与均匀性 |

P0～P3、`Q设计`、`Q驱动` 和 `q吸` 的图中位置及运行状态记录要求见[工程图读图与测点](diagram-walkthrough.md)。
