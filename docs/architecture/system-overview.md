# 系统原理

> 文档类型：V4 当前设计事实
> 最后核对日期：2026-07-24  
> 事实来源：ADR 0002、ADR 0003、v4 工程拓扑和接口规格事实簿

## 设计基准接法

```text
肥料桶 → 过滤头 → 调节阀 → CV-F ┐
                                 ├→ MV-SOURCE（肥料/关闭/农药）→ 文丘里侧吸口
农药桶 → 过滤头 → 调节阀 → CV-P ┘

水源 → 倒流防止器 → 公共过滤器 → 双路控制器
                              ├→ A → CV-A ───────────┐
                              └→ B → 文丘里 → CV-B ──┤
                                                     └→ A/B合流 → MV-END（滴灌/关闭/喷灌）
                                                                  ├→ 滴灌减压 → 滴灌主管 → 压力补偿滴头
                                                                  └→ 喷灌过滤/调压 → 喷灌管 → 上空喷头
```

水源仍只有一条入口。B 路不存在绕过文丘里的直通管；肥料与农药两条吸液支路只在文丘里侧吸口前汇流。A/B 必须先合流，再分配至滴灌或喷灌末端。

## 五种合法模式

| 现场模式 | 手机 A/B | MV-END | MV-SOURCE |
|---|---|---|---|
| 停止 | A/B 均关 | 关闭 | 关闭 |
| 清水滴灌 | A | 滴灌 | 关闭 |
| 滴灌施肥 | A→B→A | 滴灌 | 肥料 |
| 清水喷灌 | A | 喷灌 | 关闭 |
| 上空喷药 | A→B→A | 喷灌 | 农药 |

当前通过两只三通手动阀选择模式，手机端仍只控制原 A/B。每只阀只能处于一个锁定位置，因此液源和末端不会各自双开；运行规则仍禁止“农药+滴灌”和“肥料+喷灌”。换模式前先关闭 A/B，再将两只阀转到中位关闭，最后选择新位置。

## 防倒流与隔离

1. 水源侧倒流防止器保护上游水源，不能由普通控制阀或支路止回阀替代。
2. CV-A、CV-B 阻止合流点向未工作控制器出口反压，可选满足压力、压损和介质兼容要求的工程塑料止回阀，不要求黄铜。
3. CV-F、CV-P 分别阻止文丘里侧吸口向肥料桶和农药桶倒灌，优先采用耐对应母液的工程塑料低开启压力止回阀。
4. MV-SOURCE 提供液源选择与中位隔离；MV-END 提供末端选择与中位隔离，均不替代止回保护。

## 两个末端独立调压

原公共减压阀移到滴灌支路，以适配压力补偿滴头；该件是减压/调压阀，不是止回阀，可采用适合 8 L/h 工况的塑料滴灌调压器。9/12 滴灌支路不另加止回阀。喷灌支路另设过滤器和调压阀，其过滤精度、设定压力和管径均由拟购喷头及具体农药制剂要求决定。喷灌管不能直接认定为现有 9/12 PE 管。

## 分段验证

| 区段 | 当前设计事实 | 验证 |
|---|---|---|
| 共用上游 | 单一水源依次经过倒流防止器、公共过滤器和控制器 | P0、总流量 |
| A 路 | 清水旁路，经 CV-A 合流 | 检查 B 路及两桶无反向窜流 |
| B 路 | 全部驱动水穿过共用文丘里，再经 CV-B 合流 | 两个工况分别记录 P1、P2、驱动流量和吸液量 |
| 公共下游 | A/B 合流后进入 MV-END 三通选择阀 | P3 |
| 滴灌 | MV-END 滴灌位、滴灌减压、主管和压力补偿滴头 | P4、滴头流量及均匀性 |
| 喷灌 | MV-END 喷灌位、独立过滤/调压、喷灌管和上空喷头 | 最不利端 P5、喷头流量及水力均匀性 |

## 分阶段实施

当前阶段只验证手动水路：两只带中位全关的三通选择阀人工换位，不安装新增电气控制。五种合法模式、水力数据、防倒流和防串液全部验收后，第二阶段再选择带位置反馈和失电安全状态的电动三通执行器；升级不得改变本页的三通选择拓扑。
