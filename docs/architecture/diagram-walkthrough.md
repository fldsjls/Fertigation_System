## 从水源到 A/B 合流

```text
水源 → 倒流防止器 → 公共过滤器 → 太阳能4G双路控制器
                                  ├→ A → CV-A ─────────────────────┐
                                  └→ B → T1 ┬→ PRV-B ────────┬→ T2 → CV-B ─┤
                                             └→ 阀→文丘里→CV-V┘             │
                                                                            └→ A/B合流
```

A 路是清水直通。B 路进入 T1 后同时流经两条并联路径：

- 减压阀主路：`T1 → PRV-B → T2`；
- 文丘里旁路：`T1 → 旁路启用阀 → 文丘里 → CV-V → T2`。

B 路运行时不能只打开文丘里旁路并关闭减压主路。两路在 T2 合流后再经过 CV-B。P1、P2 分别测 T1、T2 公共节点的动态压力，因此两条路径承受相同的 `P1-P2`；计算 B 路压力预算时只扣除一次该压差。

## 合流后的 L 型末端选择

```text
A/B合流 → P3 → MV-END（普通L型三通，仅二选一）
                    ├→ 滴灌：可选调压 → P4 → 9/12主管 → 5个节点
                    └→ 喷淋：过滤 → 调压 → 喷淋管 → 5个喷淋点 → P5
```

`MV-END` 只有“滴灌”和“喷淋”两个连通状态，没有关闭位。必须选择 L 型阀芯；T 型阀芯可能同时连通两个出口，不符合设计。停机时 A/B 均关、液源关闭，末端阀可以保留在原位置。

## 五个滴灌节点

每个节点的正式结构相同：

```text
9/12主管 ── 12mm等径快插三通 ── 继续主管
                         │
                   12mm快插球阀
                         │
              OD12可更换PE滴头支管
               ├─ PC滴头 → 3/5毛管 → 滴箭
               └─ PC滴头 → 3/5毛管 → 滴箭
                         │
                    末端冲洗阀
```

快插接头按管外径选择，倒刺按软管内径选择。9/12 主管为 ID9/OD12；OD12 节点支管的内径、壁厚、长度和耐压仍待产品/现场确认；3/5 毛管为 ID3/OD5。旧候选方案中的 12→8 变径三通、8 mm 短管和 4/7 支路不再属于正式拓扑。

## 两条液源链路

```text
肥料清水试桶 → 过滤头 ┐
                       ├→ MV-SOURCE（肥料/关闭/农药）→ 文丘里侧吸口
农药清水试桶 → 过滤头 ┘
```

液源选择阀保留三个明确位置，肥料和农药软管及过滤件应分开并核对材料兼容性。肥料只允许配滴灌，农药只允许配喷淋。

滴灌施肥和上空喷药必须分别形成一组 P1/P2、实际文丘里驱动流量、吸液量和厂家曲线记录。`P1≤P2` 时文丘里压差不成立，判为“不适用”。

## 流量边界

- `Q滴灌 = 10 × q滴头`
- `Q喷淋 = 5 × q喷头`
- `Q节点支管 = 2 × q滴头`
- `Q毛管 = q滴头`
- `Q末端 = Q减压主路 + Q文丘里驱动 + q吸`

最后一个式子说明：文丘里实际驱动流量只是 B 路并联总流量的一部分，不能用 `Q末端-q吸` 反推。

## 现场清水记录

| 模式 | A/B 程序 | 末端 / 液源 | 至少记录 |
| --- | --- | --- | --- |
| 停止 | 均关 | 保持原位 / 关闭 | 无持续出水、无桶液位反升 |
| 清水滴灌 | A | 滴灌 / 关闭 | P0、P3、P4、10 只滴头流量及均匀性 |
| 滴灌施肥模拟 | A→B→A | 滴灌 / 肥料 | P0～P4、实际驱动流量、吸液量、冲洗终点 |
| 清水喷淋 | A | 喷淋 / 关闭 | P0、P3、P5、5 个喷头总流量及覆盖 |
| 上空喷药模拟 | A→B→A | 喷淋 / 农药 | P0、P1、P2、P3、P5、实际驱动流量、吸液量和置换时间 |

任何异常串液、双末端同时出水、`P1≤P2` 或液源桶反向进水都应立即关闭 A/B 并停止调试。
