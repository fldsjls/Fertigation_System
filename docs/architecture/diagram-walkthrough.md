## 从左到右读取主水路

| 区段 | 图中路径 | 需要确认 |
| --- | --- | --- |
| 共用上游 | 水源 → 倒流防止器 → 120目过滤器 → 双路控制器 | 水源保护等级、过滤精度、P0 动态压力 |
| A 路清水 | A 出口 → A 止回阀 → 合流点 | 清水预灌和冲洗时无水反向进入 B 路 |
| B 路施肥 | B 出口 → 文丘里大入口 → 大出口 → B 止回阀 → 合流点 | `Q驱动`、P1、P2 和厂家性能曲线同时满足 |
| 共用下游 | 合流点 → 减压阀 → 9/12 PE 主管 → N 个滴头 | P3 满足滴头工作压力，主管流量为 `Q设计` |

A、B 是两条并联供水路径，但程序中互斥运行。B 路开启时，全部驱动水必须通过文丘里两个水平大口；肥液只从小型侧吸口进入。

## 吸肥链路

吸肥方向为：

```text
肥液桶 → 桶内过滤头 → 调节阀 → 吸肥止回阀 → 文丘里侧吸口
```

`q吸` 是进入文丘里的肥液流量。吸肥止回阀用于阻止水倒灌至肥液桶，不能代替水源侧倒流防止器，也不能代替 A/B 合流前的支路止回阀。

四个测点可以共用一块量程合适的便携压力表，不要求永久安装四块表。所有记录必须是对应运行状态下的动态压力，静态压力不能用于证明文丘里或滴头工况。

## 三个流量的关系

```text
Q设计 = N × q滴头
Q设计 = Q驱动 + q吸
ΔP文丘里 = P1 - P2
P3 ≥ 滴头最低工作压力
```

- `Q设计`：进入下游主管并由滴头排出的总流量。
- `Q驱动`：从 B 出口进入文丘里大入口的清水流量。
- `q吸`：从肥液桶进入文丘里侧吸口的肥液流量。

厂家曲线中的驱动流量应与 `Q驱动` 比较，而主管和滴头的流量预算使用 `Q设计`。当吸液量相对灌溉流量不可忽略时，不能把两者直接视为相等。

## A → B → A 时测什么

| 阶段 | 开启路径 | 必记数据 | 判定重点 |
| --- | --- | --- | --- |
| A 预灌 | A 开、B 关 | P0、P3、滴头总流量 | 主管建压、滴头均匀、B 路无反向窜流 |
| 关闭间隔 | A/B 均关 | 压力衰减、阀门状态 | 两路不重叠，控制器能承受主管侧反压 |
| B 施肥 | A 关、B 开 | P0、P1、P2、P3、`Q设计`、`q吸` | 文丘里工作点和下游压力同时合格 |
| 关闭间隔 | A/B 均关 | 桶液位、反向窜流 | 肥液桶不被回压 |
| A 冲洗 | A 开、B 关 | P0、P3、末端电导率 | 冲洗至末端恢复到既定清水标准 |

!!! danger "文丘里硬性判定门槛"
    只有 `Q驱动`、P1、P2、对应吸液量和 P3 同时落入所购型号的有效工况，B 路才可判定为适用。缺少厂家完整曲线，或任一实测值不满足时，结论都是“不适用/无法确认”，不能按接口口径推断。

## 不满足厂家曲线时

按以下顺序处理：

1. 核对阀门方向、过滤器堵塞、软管漏气和测试方法；
2. 在滴头允许范围内评估增加同时灌溉流量；
3. 重新选择覆盖现场工作点的文丘里；
4. 若低流量系统无法建立所需压差，改用能够克服主管压力的小型计量泵。

改用计量泵后仍保留水源倒流防护、肥液过滤、耐肥材料和防回流措施，并重新计算注入量与运行时间。
