## 从水源到两个末端

单一水源经过倒流防止器和公共过滤器进入原双路控制器。A 是清水旁路；B 的全部水流从文丘里大入口进入并从大出口离开，不允许另设 B 路直通管。A/B 经各自止回阀合流后，进入 `MV-END` 三通选择阀，由一个阀位选择滴灌或喷灌。

滴灌链路为 `MV-END 滴灌位 → 滴灌减压阀 → 9/12 主管 → 3/5 支管 → 压力补偿滴头`。喷灌链路为 `MV-END 喷灌位 → 独立过滤器 → 独立调压阀 → 经计算的喷灌管 → 上空喷头`。

## 两条吸液链路

```text
肥料桶 → 过滤头 → 调节阀 → CV-F ┐
                                 ├→ MV-SOURCE → 同一文丘里侧吸口
农药桶 → 过滤头 → 调节阀 → CV-P ┘
```

两只桶、软管、调节阀和止回件均独立。两路在止回阀后进入一只 `MV-SOURCE` 三通选择阀，由肥料/关闭/农药三个锁定位置选择，随后接入同一侧吸口。

P1/P2 的位置相同，但滴灌施肥和上空喷药的总流量不同，因此必须形成两组工况记录，不能共用一个“文丘里通过”结论。

## 流量标记

- `Q滴灌 = N × q滴头`
- `Q喷灌 = M × q喷头`
- `q吸,F`：肥料桶进入文丘里侧吸口的流量。
- `q吸,P`：农药桶进入文丘里侧吸口的流量。
- `Q驱动 = Q末端 - q吸`

## 现场清水记录

| 模式 | 手机控制 | MV-END / MV-SOURCE | 至少记录 |
|---|---|---|---|
| 清水滴灌 | A | 滴灌 / 关闭 | P0、P3、P4、滴头总流量和均匀性 |
| 滴灌施肥清水模拟 | A→B→A | 滴灌 / 肥料 | P0～P4、肥料桶吸液量、止回效果 |
| 清水喷灌 | A | 喷灌 / 关闭 | P0、P3、P5、喷头总流量和均匀性 |
| 上空喷药清水模拟 | A→B→A | 喷灌 / 农药 | P0、P1、P2、P3、P5、农药桶吸液量和清水置换时间 |

停机或换液时 A/B 关闭，两只三通选择阀均置中位关闭。任何异常串液、双末端出水或桶液位反向上升都应立即停止调试。
