# 工程计算器使用说明

从计算器标题旁的“操作帮助”打开本页，可保留原窗口中的输入。

## 开始计算

网站首页直接打开计算器。依次选择系统流量、管路水力、压力预算、肥液与文丘里、喷灌与喷药、冲洗与均匀度；左侧录入参数，右侧结果随输入自动更新。手机上参数和结果按上下顺序显示。切换项目不会丢失输入。

- **载入当前设计**：读取工作簿同步生成的当前 V5 工况，会先提示覆盖已有输入。
- **载入 v5 十滴头算例**：填入十滴头透明算例。缺失的节点支管参数仍为空，不以估算替代现场数据。
- **导入／导出工况**：通过 JSON 保存、交换记录。支持既有工况格式的迁移；导入会覆盖当前表单。
- **清空工作表**：确认后清空现场输入，仅保留默认清水参数。
- **增加／减少采样**：每次调整四个滴头，允许 4～64 个采样值；按统一收集时间计算。

## 怎样理解结果

| 状态 | 含义 |
| --- | --- |
| 已计算 | 输入足以执行公式，不代表工程已经验收 |
| 待确认 | 缺少必要输入、动态压力、厂家压损或同一工况曲线 |
| 不适用 | 输入条件明确超出已录入范围或不满足计算条件 |

各结果同时给出原因或公式。采购前仍须取得阀门、喷头和文丘里厂家资料；首次施肥前以清水分别测量 P0～P5、两桶吸液量、两个末端流量与冲洗终点。农药剂量及施用方法必须来自登记标签。

## 导航与搜索

顶部横栏在计算器和参考文档中保持一致。输入关键词并提交即可查询参考文档；结果由文档站原生搜索提供。按 Esc 关闭搜索，返回顶部搜索框。手机将主导航放在第二行，文档目录按钮打开侧边目录。

## 保存与隐私

输入仅自动保存在当前浏览器，不上传。刷新时重新计算结果；同一站点的首页和独立工具地址共用记录。更换浏览器、端口或清除网站数据会影响本机记录，长期保存请导出 JSON。既有 v1/v2 本机记录仍按原规则恢复或迁移。

## 计算边界

- 管路模型覆盖滴灌主管、节点支管和代表性毛管，或喷灌主管/立管；两末端按互斥运行计算，不求解同时开启。
- 阀门、过滤器、控制器、倒流防止器、减压阀和文丘里的压损必须采用厂家数据或现场实测。
- B 路的系统总流量不能直接当作文丘里驱动流量；厂家工况之间不自动插值。
- 均匀度不内置合格阈值，理论冲洗时间仍须结合末端水质恢复判断。
- 详细公式和变量定义见[压力、肥液与冲洗计算](../design/hydraulic-calculation.md)，系统构造见[参考文档](../guide/index.md)。
